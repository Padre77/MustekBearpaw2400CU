Mustek BearPaw 2400 CU — WIA для Windows x64

Установка

1. Распакуйте весь ZIP в отдельную папку. Закройте VueScan и другие программы
   сканирования. Подключите Mustek BearPaw 2400 CU по USB и сверьте надпись
   на корпусе. Для 2400 CU Plus этот пакет не предназначен. Несколько старых
   сканеров используют один и тот же USB ID.
2. Запустите Install-BearPaw2400CU.exe. Подтвердите запрос Windows на права
   администратора. Затем прочитайте сообщение установщика и введите YES,
   если согласны добавить тестовый сертификат на этот компьютер.
3. Дождитесь сообщения об установке. Перезагрузите ПК, если этого попросит
   Windows. В диспетчере устройств появится Mustek BearPaw 2400 CU.

Сертификат и совместимость

Имя, отпечаток и срок действия тестового сертификата выводятся при установке.
Сертификат добавляется в хранилища
локального компьютера «Доверенные корневые центры сертификации» и
«Доверенные издатели». Доверие распространяется на подписи этого издателя.
Установщик не изменяет параметры загрузки и режим проверки подписей Windows.

Сканирование проверено на Windows 10 x64 и VueScan x64 9.8.60.
Работа на Windows 11 ещё не проверена.

Сканирование

В VueScan выберите источник BearPaw 2400 CU, оттенки серого и 100 dpi.
Для нескольких страниц выберите PDF и включите многостраничный PDF.
Первый лист — «Сканировать», следующие — «Сканировать+».

Отдельное окно: App\BearPaw2400CU.exe.
Для целого листа нажмите «Сканировать A4» и сохраните результат в PNG.
Для фрагмента нажмите «Предпросмотр», выделите область мышью, затем нажмите
«Сканировать выделенное». Оставляйте папки
App и Driver рядом, чтобы окно могло загрузить прошивку.

Удаление

Закройте программы сканирования. В диспетчере устройств удалите
Mustek BearPaw 2400 CU. Для удаления пакета найдите его опубликованное имя
oemNN.inf по исходному имени bearpaw2400cuwia.inf в выводе pnputil /enum-drivers.
Затем выполните от имени администратора pnputil /delete-driver oemNN.inf /uninstall,
подставив найденное имя. Если тестовый сертификат больше не нужен,
найдите его через certlm.msc в обоих хранилищах и удалите только запись
с отпечатком сертификата из Driver\BearPaw2400CUWia-test.cer.
