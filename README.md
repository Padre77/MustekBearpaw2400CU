# Mustek BearPaw 2400 CU для Windows x64

WIA-драйвер для планшетного **Mustek BearPaw 2400 CU** и отдельное окно сканирования. Драйвер использует штатный Microsoft WinUSB и проверенный профиль GT6801 для этой модели.

## Установка

Репозиторий содержит исходники. Подписанный установочный ZIP для локального использования можно собрать по инструкции ниже в разделе «Подготовка установочного ZIP».

1. Распакуйте весь архив, закройте программы сканирования и подключите сканер. Проверьте маркировку **BearPaw 2400 CU** на корпусе. USB ID `05D8:4002` используют и другие модели, включая 1200 CU. Модель 2400 CU Plus имеет другой контроллер и прошивку.
2. Запустите `Install-BearPaw2400CU.exe`. Подтвердите запрос администратора и введите `YES`, если согласны установить тестовый сертификат на этом ПК.
3. Дождитесь сообщения об установке. После установки устройство должно появиться в диспетчере устройств и в WIA под именем **Mustek BearPaw 2400 CU**.

Инструкции по установке и удалению есть в `INSTALL.txt` внутри архива и в [INSTALL-Windows.txt](INSTALL-Windows.txt).

## Сканирование

### VueScan

Выберите источник **BearPaw 2400 CU**, режим **Оттенки серого** и **100 dpi**. Для многостраничного документа выберите формат **PDF** и включите `Output → PDF multi page`. Первую страницу снимите кнопкой **Сканировать**, последующие — **Сканировать+**. Пробная версия VueScan добавляет водяной знак. [Справка VueScan](https://www.hamrick.com/vuescan/html/vuesc28.htm)

### Отдельное окно

Запустите `App\BearPaw2400CU.exe` из распакованного архива. Для целого листа нажмите **Сканировать A4**. Эта кнопка запускает полный проход сразу. Для фрагмента нажмите **Предпросмотр**, выделите прямоугольник мышью и нажмите **Сканировать выделенное**. Кнопка **Сохранить PNG** сохраняет последний полученный лист или фрагмент. Оставляйте папки `App` и `Driver` рядом.

Текущая версия сканирует в оттенках серого при 100 dpi. Для фрагмента драйвер ограничивает проход по вертикали и обрезает данные по горизонтали. Прошивка загружается в память контроллера при необходимости.

## Подпись пакета

Установщик показывает имя, срок действия и отпечаток сертификата конкретной сборки. После подтверждения установщик добавляет публичный сертификат в хранилища **Доверенные корневые центры сертификации** и **Доверенные издатели** локального компьютера. Установщик сохраняет штатные параметры загрузки и проверки подписей Windows. [Документация Microsoft по тестовым сертификатам](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/installing-test-certificates)

Установщик проверяет срок сертификата и после его истечения отклоняет пакет. Для новых установок нужно перевыпустить сертификат, подписать каталог и пересобрать ZIP.

## Сборка и диагностика

Для сборки нужны Visual Studio или Build Tools с инструментами C++ x64 и Windows SDK, а также компилятор .NET Framework x64 для оболочки и установщика. Диагностические утилиты и оболочку можно собрать сразу после клонирования. Для сборки WIA DLL положите отдельно полученную прошивку в `Driver/PS2fw.usb`, затем запустите `build.cmd` без параметров.

```powershell
.\build.cmd --tools-only
.\build\BearPaw2400CUProbe.exe
.\build\BearPaw2400CUStatus.exe
```

Первая утилита читает USB-дескрипторы. Вторая запрашивает статус GT6801 через WinUSB. Обе проверки выполняются без движения каретки.

### Команды сканирования

```powershell
.\build\BearPaw2400CUStatus.exe --load-firmware .\Driver\PS2fw.usb
if ($LASTEXITCODE -eq 0) {
    .\build\BearPaw2400CUStatus.exe --scan-a4 .\build\a4.bmp
}
```

Для калиброванного фрагмента команда `--scan-region` принимает координаты `x y width height` в пикселях при 100 dpi, путь к прошивке и новый путь к BMP. Область ограничена 827 × 1169 пикселями. `--test-scan` — короткий диагностический проход 64 × 16 при 50 dpi. `--plan-a4` и `--plan-test-scan` печатают параметры без обращения к сканеру.

Прошивка `PS2fw.usb` поставляется отдельно. Проверенный файл извлечён из пакета Arch Linux `sane-gt68xx-firmware` версии `1.0-10`, где он называется `ps2fw.usb`. SHA-256 — `f311caeea0d31124eeb3d1b90d70f41a430a987b14083f4860483c7df63bdc72`. При полной сборке этот файл встраивается в WIA DLL. [Профиль SANE для 2400 CU](https://gitlab.com/sane-project/backends/-/raw/master/backend/gt68xx_devices.c) · [Состав пакета Arch Linux](https://archlinux.org/packages/extra/any/sane-gt68xx-firmware/files/)

## Подготовка установочного ZIP

1. Соберите проект с локальной прошивкой. Скопируйте `BearPaw2400CUWia.inf` и `build/BearPaw2400CUWia.dll` в отдельную папку, например `build/signed-wia`.
2. Создайте `BearPaw2400CUWia.cat` с помощью `Inf2Cat` из WDK и подпишите его своим сертификатом подписи кода. Экспортируйте публичный сертификат в ту же папку под именем `BearPaw2400CUWia-test.cer`. Храните закрытый ключ отдельно. [Создание каталога](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/creating-a-catalog-file-for-test-signing-a-driver-package) · [Подпись каталога](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/test-signing-a-catalog-file)
3. Соберите архив. Скрипт проверяет подпись каталога и соответствие сертификата, затем включает контрольные суммы файлов в установщик.

```powershell
.\Package-Windows.ps1 -SignedDriverDirectory .\build\signed-wia
```

Архив появится в `build`. Его имя определяется версией драйвера из INF. После распаковки можно выполнить `.\Install-BearPaw2400CU.exe --verify` для проверки файлов без установки.
